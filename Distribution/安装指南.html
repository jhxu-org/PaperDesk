开始使用 PaperDesk

Mac 论文阅读、笔记、图文解读与 Chrome PDF 收集。

安装要求
macOS 14 或更新版本；通用版包含 Apple 芯片与 Intel 两种架构。Chrome 扩展需要同一台 Mac 上的 PaperDesk。Windows 暂不支持。此包为开发预览版，尚未完成 Apple Developer ID 签名／公证，也未上架 Chrome 应用商店。

1. 安装 Mac 应用

  1. 打开 PaperDesk-版本号-macOS-universal.dmg，把 PaperDesk.app 拖到旁边的 Applications 文件夹。
  2. 从「应用程序」打开 PaperDesk。请先安装到固定位置，再启用 Chrome 连接；不要直接从磁盘映像运行。
  3. 如果 macOS 因无法验证开发者而阻止打开，确认文件来自你信任的提供者后，在「系统设置 → 隐私与安全性」中找到 PaperDesk，选择「仍要打开」并按系统提示操作。具体以 Apple 的首次打开说明为准。如果提示文件损坏，请重新获取安装包并联系提供者。
  4. 安装完成后可以推出磁盘映像。首次启动可打开阅读示例，或导入自己的 PDF。

2. 连接 Chrome 扩展

  1. 在 PaperDesk 菜单栏打开 File → Chrome 扩展…，点击 启用连接。每位安装者都需在自己的 Mac 上执行一次。
  2. 推荐直接使用应用内置的扩展：点击 复制文件夹路径。也可以解压单独的 PaperDesk-Chrome-版本号.zip，把其中的 PaperDesk-Chrome 文件夹保存在固定位置。
  3. 在 Chrome 地址栏输入 chrome://extensions，打开右上角的 开发者模式，点击 加载已解压的扩展程序。这是开发预览版的手动加载方式，参见 Chrome 官方步骤。
  4. 选择含有 manifest.json 的扩展文件夹。若使用应用内置的版本，可在文件选择窗口按 ⌘⇧G，粘贴刚复制的路径并确认。不要选择 ZIP 文件，也不要选择应用安装包所在的外层目录。
  5. 在 Chrome 的扩展菜单中固定 PaperDesk · PDF 收集助手，点击折页 P 图标，在「首次使用」中点击 检查连接。
  6. 打开论文网页或 PDF，点击插件，选择文件后点击 导入到 PaperDesk；按提示允许该网站权限。也可在 PDF 链接上右键导入。

加载后请保留扩展文件夹。应用内置版本会随应用更新；更新后到扩展管理页点「重新加载」。单独 ZIP 版本需要替换原文件夹中的内容再重新加载。扩展 ID 固定为 cmahkelbeldefdjkebioakmadgmbfbod。不要重复安装两个副本。

当前是开发者模式试用包。面向大众的一键安装和自动更新需要后续上架 Chrome 应用商店；此 ZIP 不是可直接双击安装的 CRX。

选择存储位置与可选云端备份

点击侧栏底部「存储设置」，选择本地文件夹并确认迁移。应用会在所选位置创建 PaperDesk Library，复制并校验论文、文件夹、笔记、阅读进度和对话后切换；原位置保留副本，之后的修改只写入新位置。已有同名文件夹不会被覆盖。也可通过「打开已有书库」切换到另一份完整书库。

新位置会记住到下次启动。外置磁盘未连接时，先连接磁盘再点击「重新连接原位置」。百度网盘是可选的手动备份方式，在存储设置中启用并配置；未启用也可完整使用本地阅读和笔记功能。

3. 配置你的模型

在 PaperDesk「模型设置」中填写自己的兼容接口地址、模型名称和 API Key。API Key 保存在你自己的 Mac 钥匙串中。支持视觉输入的模型可开启「向模型发送页面图片」，解读中可展示原文配图、放大查看、跳回 PDF；普通文字模型仍可根据正文和图注回答。

安装包不包含提供者的论文、笔记、聊天记录、API Key 或百度网盘授权。每位使用者独立配置。提问时会将相关正文、近期对话及已启用的页面图片发送给使用者配置的模型服务；浏览器导入的 PDF 传至本机书库。

常见情况

  • 插件提示找不到本机程序：确认从「应用程序」打开 PaperDesk，再点一次「启用连接」。移动或重新安装应用后也需重新启用。
  • 浏览器里仍是旧图标：到 chrome://extensions 找到 PaperDesk，点击重新加载。
  • 无法读取钥匙串（-25293）：在模型设置中点击「重试读取钥匙串」，按系统提示授权。也可重新填写 API Key，取消「在钥匙串中记住 API Key」，点击「保存并仅本次使用」。临时密钥退出后失效，原有钥匙串记录保留。百度网盘提供相同的仅本次运行选项。预览版更新可能影响旧凭据的访问权限。
  • 网站无法导入：确认允许了该网站权限。需要登录的 PDF 仍受网站限制；blob 地址可先下载后导入。普通网页不会自动转成 PDF，单份导入限制 100 MB。
  • 公司电脑无法开启开发者模式：可能受组织策略管理，需要联系管理员。此包未提供企业部署策略。
  • 更新已有应用：先等待后台导入和回答完成、保存草稿，退出旧版本，再用新版本替换「应用程序」中的 PaperDesk。书库保存在用户目录中，不随应用包替换。
本包无需 Xcode、Python、Node.js 或源代码。适用于受邀试用；Apple 芯片版本已在开发机验证，Intel 版本已完成交叉编译与架构校验，尚未在 Intel 实机验证。
